Configurar acessos

Feito uma vez, pela dona do site. Cria os logins de quem usa a Central de Distratos.

Voltar ao site

1. Chave do GitHub

O site usa uma chave (token) do GitHub para guardar os contratos e os distratos no repositório privado. Para criar:

  1. No GitHub: Settings › Developer settings › Personal access tokens › Fine-grained tokens › Generate new token.
  2. Em Repository access, escolha Only select repositories e marque central-distratos e central-distratos-dados.
  3. Em Permissions › Repository permissions: Contents: Read and write e Actions: Read-only.
  4. Gere e cole aqui. A chave não aparece para ninguém: ela fica guardada trancada pela senha de cada pessoa.

2. Pessoas

Cada pessoa entra com o nome e a própria senha.
